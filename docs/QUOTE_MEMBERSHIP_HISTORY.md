# Saved quote membership history

Optional additive migration22 binds new v2 saved quote proposals to server-owned requester and selected-manager membership generations. A committed deactivation or workspace move advances that person's quote generation exactly once; reactivation never restores old saved authority. Current saved-authority lookup and duplicate save replay compare the stored generations with active same-workspace membership under workspace/member locks. Historical v1/v2 reads retain exact proposal bytes. Pre22 plans have no generation binding and default-deny future saved authority; prepare new bound work rather than silently upgrading them.

Apply with the separate migration-owner connection using `node --import tsx scripts/quote-membership-setup.ts`. It requires exact released prerequisite digests1/3/10/12/19/20/21, bounded database/lock timeouts and idempotent migration22 digest validation. Existing migrations are unchanged. Runtime gets SELECT-only membership history; membership enrollment/lifecycle remains administrator-owned. No function is SECURITY DEFINER. The database owner can bypass triggers and remains outside this protection boundary.

Installing22 deliberately changes membership lifecycle for all existing/new workspace identities, even members with no saved quote: the history foreign key prevents deletion/reinsertion, and rename is refused. Deactivate identities instead. Existing application member deletion/rename operations were not found during this review. This is an explicit anti-resurrection constraint, not a behavior-free metadata addition. It does not permanently revoke all authentication sessions or establish any generalized identity system.

Direct member revocation while a workspace reader holds its lock refuses with NOWAIT; that failed transaction has not revoked the member. The caller must rollback, retry and verify committed current state. Plan INSERT takes shared NOWAIT current-member locks after the workspace lock. A contending direct member update refuses proposal persistence; after rollback, a fresh valid insert can bind actual generations. There is no general deadlock-free claim.

This remains saved-proposal authority containment only. No independent action approval, connector dispatch, quote provider conformance, workflow engine or live delivery is enabled. Future delayed submission/approval/dispatch must revalidate current membership history, designated manager grant, scope, policy, source versions, exact requests, recovery epoch and provider capabilities inside their actual mutation boundary. Pricing/request plan JSON and existing hashes are not rebound or rewritten by migration22.
